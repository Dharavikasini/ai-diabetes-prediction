# 🩺 AI Diabetes Prediction System

An advanced Machine Learning based healthcare application that predicts diabetes risk using patient health parameters.

Built using:
- Python
- Streamlit
- XGBoost
- Scikit-learn
- Pandas
- Machine Learning

---

# 🚀 Features

✅ AI-powered diabetes prediction  
✅ Interactive Streamlit dashboard  
✅ Risk percentage analysis  
✅ Health insights and warnings  
✅ Feature scaling and preprocessing  
✅ Modern colorful UI/UX  
✅ Data visualization charts  
✅ Machine Learning backend  

---

# 🧠 Machine Learning Model

This project uses:

## XGBoost Classifier

The model is trained using:
- Glucose Level
- BMI
- Blood Pressure
- Age
- Insulin
- Pregnancies
- Skin Thickness
- Diabetes Pedigree Function
